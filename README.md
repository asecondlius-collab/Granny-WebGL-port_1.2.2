# Granny-WebGL-port_1.2.2

Granny-WebGL-port_1.2.2 This is a WebGL port built from Granny Version 1.2.2 using Unity Editor 2019.2.11f1. To run the game, you must install these files and then use a program like NodeJS or Python to host it. For example, on NodeJS, you can install it, go to the directory of where the index.html is, and then run "npx serve" to run the game and be able to play it. Otherwise on Python, you also go to the directory of where index.html is, and run something like "python -m http.server 8000". Note that you must at least host it, you cannot just open the file and expect it to work. The gameplay will also be slow at times with great lag, because WebGL is not as powerful as other renderers. I've spent weeks bug-testing it, so hopefully there are not any major bugs associated with it.
